Welcome to **Neon Blast**! If you love the highly addictive gameplay structure of **Block Blast**, you will feel right at home here—but with a vibrant, cyberpunk-inspired neon twist. 

This is a lightweight, dependency-free puzzle game built entirely with Vanilla JavaScript, HTML5, and CSS3. 

## 🎮 What is Neon Blast?
Neon Blast is a strategic block-puzzle game. Your goal is to drag and drop uniquely shaped neon blocks onto an 8x8 grid. Fill complete rows or columns to clear them and rack up combo points! The game ends when there is no more space to place the given shapes.

If you are a fan of Tetris-style mechanics or structural puzzle games like Block Blast, this open-source project is a great example of how to build those mechanics from scratch.

## ✨ Features
* **Familiar Mechanics:** Block Blast-inspired gameplay that is easy to learn but hard to master.
* **Three Difficulty Levels:** Choose between Easy, Medium, and Hard (featuring complex 3x3 shapes!).
* **Synthesized Audio System:** Zero external sound files! All sound effects are generated directly via the Web Audio API.
* **Local High Scores:** Your top scores are automatically saved to your browser's `localStorage`.
* **Mobile-First UI:** 100% responsive design that fits perfectly on mobile screens without annoying scrolling or overlapping.
* **Combo Multipliers:** Clear multiple lines at once to trigger massive combo points and visual feedback.

## 🚀 How to Play (Run Locally)
Since this project uses pure front-end technologies with no frameworks or build tools, running it is incredibly simple:

1. Clone this repository to your local machine:
   ```bash
   git clone [https://github.com/yourusername/neon-blast.git](https://github.com/yourusername/neon-blast.git)
Navigate to the folder.

Open index.html in any modern web browser (Chrome, Safari, Firefox, Edge).

Select your difficulty and start playing!

Styling: CSS3 (Custom variables, animations, and glowing neon box-shadows)
